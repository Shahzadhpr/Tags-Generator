# JavaScript Tags Generator 🚀

A simple yet powerful JavaScript project to help you generate, manage, and customize tags effortlessly. 🎯 Perfect for quick data organization and creative labeling! ✨

&nbsp;

## Features ✨

- **Add Tags:** Type your tag and press Enter or comma to add. 📝
- **Limit:** Up to 10 tags maximum — keep it clean and organized. 📋
- **Remove Individual Tag:** Each tag has a close (×) icon for quick deletion. ❌
- **Remove All:** Clear all tags at once with one click. 🧹
- **Tag Counter:** Real-time count showing how many tags are left to add. 📊
